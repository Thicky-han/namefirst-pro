# NameFirst Pro

![藍色 Pro 圖示](./assets/brand/icon-128.png)

**名稱優先，在搜尋當下核對證據。** NameFirst Pro 是適用於電腦版 Chrome、Edge 的獨立開源擴充功能：在 Bing／百度搜尋中判斷是否正在尋找某個官方入口，為未收錄的名稱主動發現候選，並在獲得權限後現場讀取、核對公開證據。專案採用 **AGPL-3.0-only**，允許依授權條款商用。

## 可以做什麼

- 每次支援的搜尋都在本機推斷「找入口／查資料／不確定」，無須先把名稱加入固定目錄。
- 導航任務按預算收集當前候選與公開證據，顯示確切網址、用途、來源、時間及結果；證據不足時可拒絕判定。
- 保留搜尋引擎原始結果，不自動跳轉、下載或執行檔案。
- 只有明確的意圖回饋才訓練本機模型。個人入口、別名與排除記錄獨立管理，個人收藏不等於官方認證。
- 支援編輯、刪除、單步復原及 JSON 備份預覽／合併／取代；Chrome／Edge 間可手動遷移。

## 下載與安裝

一般使用者不需要 Node.js、帳號、API Key 或專案後端，也無須編譯。

1. 在 [Releases](https://github.com/Thicky-han/namefirst-pro/releases) 開啟正式版本 `v1.0.0`。Chrome 下載 `namefirst-pro-1.0.0-chrome.zip`，Edge 下載 `namefirst-pro-1.0.0-edge.zip`。`namefirst-pro-1.0.0-source.zip` 是對應原始碼，不是可直接載入的擴充功能。
2. 將 ZIP **完整解壓縮**至長期保留的資料夾；不要直接從壓縮檔載入，也不要在安裝後刪除該資料夾。
3. 開啟 `chrome://extensions` 或 `edge://extensions`，啟用「開發人員模式」，選取「載入未封裝項目」。
4. 選擇**直接包含 `manifest.json`** 的解壓縮資料夾，而非外層資料夾。確認已載入 **NameFirst Pro**，必要時將藍色 NF／PRO 圖示固定在工具列。
5. 開啟擴充功能視窗，確認總開關及所需搜尋引擎開關已啟用。若要進行外部取證，按「开启联网核验权限」，閱讀並接受瀏覽器的 HTTPS 網站存取提示。此權限可撤銷；未授權時不讀取外部證據。
6. 在一般電腦版 Bing／百度網頁搜尋輸入 `Apache Arrow official website`。閱讀卡片的**當前狀態、確切入口、來源與時間**；只有符合政策的當次證據才可支持官方歸屬。陌生名稱也可進入發現流程，但不保證取得認證。

完整操作見[英文安裝教學](./INSTALL.en.md)／[簡體中文教學](./INSTALL.md)。

## 回饋、備份與更新

誤把資料查詢當成導航時，按「这次查资料」。需要找入口時可選「我在找入口」；「仅本次按入口核验」只確認這一次，不儲存訓練標籤。跳過或不點擊不會訓練。學習與詢問提示可分別關閉，個人網址仍清楚標為未認證。

透過「管理记录、查看历史证据与备份迁移」開啟管理頁，按「导出 JSON 备份」。在新瀏覽器選取備份，選擇合併／取代，先「预览导入」，核對記錄與衝突後再確認。合併保留衝突的本機記錄；取代覆寫個人與學習資料。權限、偏好、歷史證據及復原記錄不在備份內，需另行設定。未知或損壞格式不覆寫現有資料。備份可能含手動輸入的名稱與網址，請自行妥善保管。

更新前先備份；完整解壓縮新版並取代載入資料夾中的檔案，在擴充功能管理頁按「重新載入」，再重新整理搜尋分頁。單純覆寫磁碟檔案可能仍執行舊的背景程式。**不要先解除安裝**，否則本機資料會被移除；相同擴充身分與設定檔通常可保留資料，但不保證所有未來格式都相容。

沒有卡片時，確認網址／版型受支援、總開關與引擎開關已啟用、更新後已重新整理分頁。有卡片但無法核驗時，檢查外部權限、網路及狀態原因。驗證碼、登入、限流與逾時會導致停止或拒絕判定，不會繞過。也可暫停引擎或撤銷權限。詳見[管理](./MANAGEMENT.md)。

## 真實範圍與隱私

目前唯一可得出肯定歸屬的權威政策，涵蓋 Apache 維護目錄明確列出的專案**首頁／下載入口**。Wikidata 僅提供線索。排名、HTTPS、網站自稱、模型分數與個人選擇均不能單獨證明官方身分；沒有通用的文件／登入入口政策，也不保證全網認證、軟體安全或法律資格。

支援已識別的電腦版 Bing HTTPS `/search`（`www.bing.com`、`cn.bing.com`、`bing.com`）及 `www.baidu.com/s` UTF-8 網頁結果。手機、圖片／新聞搜尋、隱藏或未知版型不在承諾範圍。依維護者要求，一般真實線上驗收未列為本階段門檻；受控瀏覽器測試與歷史線上記錄分開呈現。

沒有遙測、遠端訓練或自動上傳回饋；不儲存完整搜尋歷史。明確標籤與個人記錄保存在本機。獲准取證後，所訪問的網站仍可能看到 IP 與請求網址，補充發現可能向搜尋引擎傳送相關名稱，因此並非全離線或網路匿名。歷史證據一律標為快取，失敗的更新不會刷新核驗時間；當次導航仍收集當前證據。見[隱私說明](./PRIVACY.md)及[學習邊界](./LEARNING.md)。

[公開評測](./EVALUATION.md)：36 筆人工撰寫、使用真實軟體名稱的查詢中，既有訓練模型答對 25、拒絕判定 6，並把 5 筆資料查詢誤判為導航。24 個合成信任案例中，23 個符合期望狀態；3 次認證中誤認證為 0。另 1 個文件用途安全地拒絕判定，仍屬能力未達目標。這些數字不是實際使用者流量或全網準確率。

## 建置與授權

開發需 Node.js 24+、pnpm 11.25.0：

```powershell
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm evaluate:release
pnpm build
```

封裝另需 Git、Python 3.9+，使用 `pnpm release:prepare` 及 `pnpm release:verify`。發布檔案附 `SHA256SUMS`，可用 `Get-FileHash -Algorithm SHA256 <檔名>` 核對；雜湊一致不代表安全保證。

這是獨立實作與 Git 歷史。依維護者授權，以原版 NF／箭頭圖案精修的藍色 Pro 衍生圖示已獲確認；原創程式及該衍生圖案採用 AGPL-3.0-only，相依套件保留各自授權。見[品牌來源](./assets/brand/README.md)、[相依套件](./DEPENDENCIES.md)、[LICENSE](./LICENSE)、[發行說明](./RELEASE_NOTES.md)及[貢獻方式](./CONTRIBUTING.md)。
