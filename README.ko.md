# NameFirst Pro

![파란색 Pro 아이콘](./assets/brand/icon-128.png)

**이름을 먼저, 근거는 검색 시점에 확인합니다.** NameFirst Pro는 데스크톱 Chrome/Edge용 독립 오픈 소스 확장 프로그램입니다. Bing/Baidu 검색이 공식 사이트의 특정 진입점을 찾는 요청인지 판단하고, 기존 목록에 없는 이름도 후보를 발견합니다. 허용된 경우 그 자리에서 공개 근거를 읽고 소속을 확인합니다. **AGPL-3.0-only** 조건을 지키면 상업적으로도 사용할 수 있습니다.

[简体中文](./README.md) · [繁體中文](./README.zh-TW.md) · [English](./README.en.md) · [日本語](./README.ja.md) · [한국어](./README.ko.md) · [Français](./README.fr.md) · [Deutsch](./README.de.md) · [Español](./README.es.md) · [Português](./README.pt-BR.md)

**첫 버전은 `1.0.0`이며 파란색 브랜드는 승인되었습니다.** [공식 Releases](https://github.com/Thicky-han/namefirst-pro/releases)에서 받으세요. `v1.0.0`이 아직 없다면 관리자의 최종 공개 확인을 기다리는 중이며 설치 패키지도 아직 공개되지 않은 것입니다. 소스 ZIP은 바로 설치하는 패키지가 아닙니다. **현재 UI는 중국어 간체**이며, 9개 언어 README는 9개 UI 언어를 뜻하지 않습니다.

## 주요 기능

- 지원되는 검색마다 탐색/정보/불확실 의도를 로컬에서 추론합니다. 이름을 미리 목록에 등록할 필요가 없습니다.
- 탐색 작업은 제한된 예산 안에서 현재 후보와 공개 근거를 모아 정확한 주소, 용도, 출처, 시각, 상태를 보여 줍니다. 근거가 부족하면 판단을 보류합니다.
- 원래 검색 결과를 유지하며 자동 이동, 다운로드, 파일 실행을 하지 않습니다.
- 명시적인 의도 피드백만 로컬 모델을 학습시킵니다. 개인 URL, 별칭, 제외 기록은 별도로 관리되며 공식 인증을 부여하지 않습니다.
- 편집/삭제/직전 변경 취소, JSON 미리보기 후 병합/교체, Chrome/Edge 간 수동 이동을 지원합니다.

## 다운로드와 설치

완성 ZIP 사용자는 Node.js, 계정, API 키, 프로젝트 서버나 컴파일이 필요 없습니다.

1. [Releases](https://github.com/Thicky-han/namefirst-pro/releases)에서 정식 `v1.0.0`을 엽니다. Chrome은 `namefirst-pro-1.0.0-chrome.zip`, Edge는 `namefirst-pro-1.0.0-edge.zip`을 받습니다. `namefirst-pro-1.0.0-source.zip`은 대응 소스 코드입니다.
2. ZIP의 **모든 파일**을 계속 보관할 폴더에 풉니다. ZIP 안에서 로드하거나 설치 후 폴더를 삭제하지 마세요.
3. `chrome://extensions` 또는 `edge://extensions`를 열고 개발자 모드를 켠 다음 압축 해제된 확장 프로그램 로드를 선택합니다.
4. **`manifest.json`이 바로 들어 있는 폴더**를 선택합니다. 그 바깥 폴더를 선택하지 마세요. **NameFirst Pro**가 로드되었는지 확인하고 필요하면 파란 NF/PRO 아이콘을 도구 모음에 고정합니다.
5. 팝업에서 전체 및 사용할 검색 엔진 스위치를 켭니다. 외부 근거를 읽으려면 “开启联网核验权限”를 누르고 HTTPS 사이트 접근을 요청하는 브라우저 안내를 읽은 후 허용합니다. 권한을 취소할 수 있으며 허용 전에는 외부 근거를 읽지 않습니다.
6. 일반 데스크톱 Bing/Baidu 웹 검색에서 `Apache Arrow official website`를 검색합니다. 카드의 **현재 상태, 정확한 진입 주소, 출처, 시각**을 읽으세요. 현재 근거가 정책을 충족할 때만 공식 소속을 지지합니다. 새 이름도 발견 절차에 들어가지만 인증이 보장되지는 않습니다.

더 자세한 절차는 [영어 설치 안내](./INSTALL.en.md) 또는 [중국어 간체 안내](./INSTALL.md)에 있습니다.

## 피드백, 백업, 업데이트

정보 검색을 탐색으로 잘못 판단하면 “这次查资料”를 선택합니다. “我在找入口”는 진입점을 찾는다는 의도를 알립니다. “仅本次按入口核验”는 이번 작업만 확인하고 학습 라벨은 저장하지 않습니다. 건너뛰기나 클릭하지 않는 행동은 학습시키지 않습니다. 학습과 질문 표시를 각각 끌 수 있으며 개인 URL은 미인증으로 구분됩니다.

“管理记录、查看历史证据与备份迁移”로 관리 화면을 열고 “导出 JSON 备份”로 저장합니다. 새 브라우저에서 파일과 병합/교체 방식을 고르고 “预览导入”으로 기록 및 충돌을 검토한 뒤 확정합니다. 병합은 충돌하는 로컬 기록을 유지하고 교체는 개인/학습 데이터를 덮어씁니다. 권한, 설정, 과거 근거, 취소 기록은 백업에 포함되지 않아 별도로 설정해야 합니다. 알 수 없거나 손상된 형식은 기존 데이터를 덮어쓰지 않습니다. 백업에는 직접 입력한 이름/URL이 있으므로 안전하게 보관하세요.

업데이트 전 백업하고 새 버전을 모두 풀어 로드된 파일을 교체합니다. 확장 관리 화면에서 다시 로드한 다음 검색 탭도 새로 고칩니다. 디스크 파일 교체만으로는 이전 백그라운드 프로세스가 남을 수 있습니다. **먼저 제거하지 마세요.** 로컬 데이터가 삭제됩니다. 동일한 확장 ID와 프로필은 보통 데이터를 유지하지만 모든 미래 형식의 호환성을 보장하지는 않습니다.

카드가 없으면 지원 URL/레이아웃, 전체 및 엔진 스위치, 업데이트 후 탭 새로 고침을 확인하세요. 근거를 확인할 수 없으면 외부 권한, 네트워크, 표시된 이유를 확인하세요. CAPTCHA, 로그인, 속도 제한, 시간 초과에서는 중단하거나 판단을 보류하며 우회하지 않습니다. 엔진을 일시 중지하거나 권한을 취소할 수도 있습니다. [관리 안내](./MANAGEMENT.md).

## 범위와 개인정보

현재 공식 소속을 긍정할 수 있는 유일한 권위 정책은 Apache가 관리하는 프로젝트 디렉터리에 명시된 **홈페이지/다운로드 진입점**입니다. Wikidata는 단서만 제공합니다. 순위, HTTPS, 자체 주장, 모델 점수, 개인 선택만으로는 공식 신원을 증명할 수 없습니다. 일반 문서/로그인 정책이나 전체 웹 인증, 소프트웨어 안전성/법적 자격 보장은 없습니다.

인식 가능한 데스크톱 Bing HTTPS `/search`(`www.bing.com`, `cn.bing.com`, `bing.com`) 및 `www.baidu.com/s` UTF-8 일반 웹 검색만 지원합니다. 모바일, 이미지/뉴스 검색, 숨김/미지원 레이아웃은 범위 밖입니다. 관리자 요청으로 일반 실제 온라인 인수 확인은 이번 단계 조건에서 제외했으며, 통제된 브라우저 시험과 과거 온라인 기록을 구별해 보고합니다.

원격 측정, 원격 학습, 자동 피드백 업로드와 전체 검색 기록 저장이 없습니다. 명시 라벨과 개인 기록은 로컬에 저장됩니다. 권한 부여 후 방문한 사이트는 IP와 요청 URL을 볼 수 있고, 추가 발견 과정에서 검색 엔진에 관련 이름을 보낼 수 있습니다. 따라서 완전한 오프라인이나 익명 통신은 아닙니다. 과거 근거는 항상 캐시이며 실패한 갱신은 인증 시각을 바꾸지 않습니다. 현재 탐색 작업은 현재 근거를 수집합니다. [개인정보 안내](./PRIVACY.md), [학습 범위](./LEARNING.md).

[공개 평가](./EVALUATION.md): 실제 소프트웨어 이름으로 직접 작성한 36개 질의에서 기존 학습 모델은 25개 정답, 6개 보류, 정보 질의 5개를 탐색으로 오판했습니다. 합성 신뢰 사례 24개 중 23개가 기대 상태와 일치했고 인증 3개 중 오인증은 0개입니다. 문서 사례 1개는 안전하게 보류했지만 기능 목표에는 미달했습니다. 실제 이용자 표본이나 전체 웹 정확도 추정이 아닙니다.

## 개발과 라이선스

개발에는 Node.js 24+, pnpm 11.25.0이 필요합니다.

```powershell
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm evaluate:release
pnpm build
```

패키징에는 Git, Python 3.9+, `pnpm release:prepare`, `pnpm release:verify`도 필요합니다. 배포의 `SHA256SUMS`와 `Get-FileHash -Algorithm SHA256 <파일명>`으로 대조할 수 있습니다. 일치는 안전성을 보장하지 않습니다.

구현과 Git 이력은 독립적입니다. 관리자 허가로 기존 NF/화살표를 다듬은 파란 Pro 파생 아이콘은 승인되었습니다. 독자 코드와 이 파생 그림은 AGPL-3.0-only이며 의존성은 각각의 라이선스를 유지합니다. [브랜드 출처](./assets/brand/README.md), [의존성](./DEPENDENCIES.md), [LICENSE](./LICENSE), [릴리스 노트](./RELEASE_NOTES.md), [기여 방법](./CONTRIBUTING.md).
