# NameFirst Pro

![Pro 아이콘 제안](./assets/brand/icon-128.png)

**이름을 먼저 보고 검색 시점의 근거를 확인합니다.** 데스크톱 Chrome/Edge의 Bing/Baidu 검색을 위한 독립 AGPL-3.0-only 확장입니다. fork가 아닙니다. `1.0.0-rc.1`은 로컬 후보이며 아이콘과 공개 배포는 승인 대기 중입니다. 아직 공개 다운로드 주소는 없습니다. UI는 중국어 간체이며 README 9개 언어가 UI 9개 언어를 뜻하지는 않습니다.

## 설치와 사용

1. 로컬 `release/1.0.0-rc.1/`에서 Chrome은 `chrome.zip`, Edge는 `edge.zip`으로 끝나는 파일을 선택하고 영구 폴더에 모두 풉니다. `source.zip`은 대응 소스이며 설치용 확장이 아닙니다.
2. `chrome://extensions` / `edge://extensions`에서 개발자 모드를 켜고, `manifest.json`이 바로 들어 있는 폴더를 압축해제 확장 로드로 선택합니다.
3. 도구 모음 팝업에서 전체/검색 엔진 스위치를 켭니다. 필요하면 “开启联网核验权限”을 선택해 브라우저 안내를 읽고 외부 HTTPS 접근을 허용합니다. 허용 전에는 외부 근거를 읽지 않으며 언제든 철회할 수 있습니다.
4. 일반 데스크톱 검색에서 `Apache Arrow official website` 등을 검색합니다. 카드의 상태, 정확한 주소, 출처와 시간을 확인하세요. 기존 검색 결과는 유지하며 자동 이동하지 않습니다.
5. 정보 검색의 오판은 “这次查资料”로 수정합니다. 명시한 라벨만 학습하며 건너뛰기/미클릭은 학습하지 않습니다. 개인 URL·별칭·거부 기록은 공식 인증과 분리됩니다.
6. 관리 화면에서 JSON을 내보내고 새 브라우저에서 파일을 선택해 병합/교체 미리보기 후 확정합니다. 충돌은 로컬 우선이며 알 수 없는 형식은 기존 데이터를 덮지 않습니다. 권한, 설정, 캐시, 실행 취소는 이동하지 않습니다.
7. 업데이트 전 백업하세요. 압축해제 파일을 교체한 뒤 확장을 새로 로드하고 검색 탭도 새로 고칩니다. 먼저 제거하면 로컬 데이터가 삭제됩니다.

자세한 [영문 설치 안내](./INSTALL.en.md), [관리](./MANAGEMENT.md), [개인정보](./PRIVACY.md)를 참고하세요. 편집/삭제/최근 한 단계 실행 취소와 동시 편집 보호를 제공합니다.

## 범위와 한계

이름이 사전 목록에 있을 필요는 없습니다. 현재 긍정 인증 정책은 Apache가 관리하는 프로젝트 디렉터리에 명시된 홈페이지/다운로드 주소로 제한됩니다. Wikidata는 후보 단서입니다. 순위, HTTPS, 공식이라는 주장, 모델 점수나 개인 선택만으로 인증하지 않습니다. 문서/로그인에 일반 정책이 없으며 모든 공식 사이트나 소프트웨어 안전을 보장하지 않습니다.

인식된 데스크톱 Bing HTTPS `/search`, `www.baidu.com/s` UTF-8 일반 웹 결과만 지원합니다. CAPTCHA, 로그인, 숨김/미지원 레이아웃, 제한/시간 초과는 중단 또는 보류하며 우회하지 않습니다. 요청에 따라 일반 온라인 인수는 이번 단계 조건에서 제외했습니다. 학습/질문을 따로 끌 수 있으며 전체 검색 기록은 저장하지 않습니다. 과거 근거는 항상 캐시로 표시하고 실패한 재검사는 이전 인증 시간을 갱신하지 않습니다.

[평가](./EVALUATION.md): 실제 소프트웨어 이름으로 직접 작성한 36개 질의에서 기존 학습 모델은 25개 정답, 6개 보류, 정보 질의 5개를 탐색으로 오판했습니다. 합성 신뢰 시나리오 24개 중 기대 상태와 23개 일치, 인증 3개 중 오인증 0개입니다. 문서 사례 1개는 안전하게 보류했지만 목표 미달입니다. 실제 이용자 표본이나 전체 웹 정확도 추정이 아닙니다.

## 개발과 라이선스

Node.js 24+ 및 pnpm 11.25.0: `pnpm install --frozen-lockfile`, `pnpm check`, `pnpm test`, `pnpm build`. 배포 준비는 Git/Python 3.9+와 `pnpm release:prepare`, `pnpm release:verify`가 추가로 필요합니다. 일반 사용자는 계정/API Key/개발 도구가 필요 없습니다. ZIP은 `SHA256SUMS`와 대조할 수 있습니다.

원본 구현과 이번에 허가한 Pro 파생 그림은 AGPL-3.0-only이고 의존성은 각 라이선스를 유지합니다. 이전 코드, 목록, 확장 ID, Git 이력을 복사하지 않았습니다. [브랜드 출처](./assets/brand/README.md) · [배포 안내](./RELEASE_NOTES.md) · [LICENSE](./LICENSE).
