## インストールと操作

1. ローカルの `release/1.0.0-rc.1/` から Chrome 用 `chrome.zip` または Edge 用 `edge.zip` で終わるパッケージを選び、永続フォルダーに全て展開します。`source.zip` は対応するソースです。
2. `chrome://extensions` / `edge://extensions` でデベロッパーモードを有効にし、`manifest.json` が直接入っているフォルダーを「展開して読み込み」で指定します。
3. ツールバーのポップアップで全体と対象エンジンを有効にします。必要なら「开启联网核验权限」で外部 HTTPS アクセスを許可し、ブラウザーの表示を確認します。未許可時は外部証拠を読みません。許可は取り消せます。
4. 通常のデスクトップ検索で `Apache Arrow official website` などを検索します。独立カードに状態、正確な入口、出典と時刻が表示されます。元の結果は残り、自動転送はしません。
5. 情報検索の誤判定は「这次查资料」で修正できます。明示ラベルだけで学習し、スキップや未クリックは学習しません。個人 URL・別名・否定記録は公式認証ではありません。
6. 管理画面から JSON を書き出し、新しいブラウザーで選択、マージ/置換のプレビュー後に確定します。競合時はローカルを優先し、不明形式は上書きしません。権限、設定、キャッシュ、取り消し履歴は移りません。
7. 更新前にバックアップします。展開ファイルを置き換え、拡張を再読み込みして検索タブも更新します。先にアンインストールするとローカルデータが消えます。

詳細は [English installation](./INSTALL.en.md)、[管理](./MANAGEMENT.md)、[プライバシー](./PRIVACY.md) を参照してください。編集・削除・直前変更の取り消し、並行編集の保護があります。

## 対応範囲と限界

名称の事前登録は不要です。現在の唯一の肯定的な権威ポリシーは Apache 管理のプロジェクトディレクトリが明示したホーム/ダウンロード入口です。Wikidata は候補の手掛かりに限られます。順位、HTTPS、自称公式、モデル値、個人選択だけでは認証しません。文書/ログインの汎用ポリシーや全サイト・ソフトの安全性の保証はありません。

認識済みのデスクトップ Bing HTTPS `/search` と `www.baidu.com/s` の UTF-8 通常結果に対応します。CAPTCHA、ログイン、非表示/未知レイアウト、制限、タイムアウトは中止または保留になります。迂回しません。通常のオンライン検収は依頼により今回の段階条件から除外しています。学習/質問は個別に無効化でき、全検索履歴は保存しません。過去の証拠は常にキャッシュ表示で、再確認失敗時も古い時刻を更新しません。

[評価](./EVALUATION.md)：実名で人工作成した 36 クエリー中、既存学習モデルは 25 正解・6 保留・5 情報検索の誤起動。合成の信頼性シナリオ 24 件中 23 件が期待と一致し、認証 3 件中の誤認証は 0。文書入口の 1 件は安全に保留し目標未達です。実利用トラフィックや全 Web の精度推定ではありません。

## 開発とライセンス

Node.js 24+ / pnpm 11.25.0 で `pnpm install --frozen-lockfile`、`pnpm check`、`pnpm test`、`pnpm build`。配布作業には Git/Python 3.9+ も必要で `pnpm release:prepare` と `pnpm release:verify` を実行します。利用者はアカウント/API Key/開発ツール不要です。ZIP の整合性は `SHA256SUMS` で確認できます。

オリジナル実装と今回許可された Pro 派生図案は AGPL-3.0-only、依存物は各ライセンスを維持します。旧実装・データ・拡張 ID・Git 履歴は継承していません。[図案の由来](./assets/brand/README.md) · [リリース情報](./RELEASE_NOTES.md) · [LICENSE](./LICENSE)。
